## ADDED Requirements

### Requirement: 터미널 스타일 채팅 UI
시스템 SHALL 자연어 입력을 받아 에이전트에게 전달하고, 응답을 터미널 형태의 채팅 UI에 표시한다.

#### Scenario: 사용자가 메시지 전송
- **WHEN** 사용자가 입력창에 "ETH 가격 알려줘"를 입력하고 전송한다
- **THEN** 사용자 메시지가 대화 목록에 즉시 표시되고, 에이전트 응답이 스트리밍으로 렌더링된다

#### Scenario: 대화 맥락 유지
- **WHEN** 직전 턴에서 ETH를 매수한 뒤 사용자가 "그거 다시 팔아줘"라고 입력한다
- **THEN** 에이전트가 이전 맥락을 참조해 해당 자산 매도를 실행한다

### Requirement: 툴 실행 결과 표시
시스템 SHALL 에이전트가 툴을 호출하면 어떤 툴이 실행되었는지 UI에 표시한다.

#### Scenario: 스왑 툴 호출
- **WHEN** 에이전트가 executeSwap 툴을 호출한다
- **THEN** 대화 목록에 "executeSwap 실행 중" 상태가 표시되고, 완료 후 결과 요약이 응답에 포함된다
